# Cryptocurrency Market Analysis Dashboard

An interactive Power BI dashboard for analysing cryptocurrency price movements, historical performance, market trends, and trading volume across selected cryptocurrency pairs from the Binance ecosystem.

## Project Overview

This project explores cryptocurrency market behaviour using historical trading data. It focuses on comparing four cryptocurrency trading pairs — BTCUSDT, ETHUSDT, BNBUSDT, and XRPUSDT — through interactive visualisations and time-based analysis.

The dashboard presents market information in a structured format to help users explore price trends, compare trading activity, and understand changes in cryptocurrency performance over time.

## Project Objectives

- Analyse historical cryptocurrency closing prices.
- Compare cryptocurrency performance across different years and quarters.
- Explore monthly and yearly market trends.
- Examine price fluctuations and market movements.
- Compare trading volume across selected cryptocurrencies.
- Present market data through interactive Power BI visualisations.

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualisation.
- **Power Query** – Data preparation and transformation (where applied).
- **DAX** – Measures and calculations (where applied).
- **Binance Market Data** – Cryptocurrency trading dataset.
